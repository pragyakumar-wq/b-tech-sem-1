Unit 1: Fundamentals of Computer Systems (8 hrs)

  • 1.1 Classification of computers, functional units
  • 1.2 CPU organization and working
  • 1.3 Memory: architecture, representation, hierarchy
  • 1.4 CPU registers, impact of cache memory on performance
  • 1.5 Motherboard and its components
  • 1.6 Von Neumann architecture
  • 1.7 Machine, assembly and high-level languages; compiler, interpreter

Unit 2: Data Representation (8 hrs)

  • 2.1 Data representation and number systems
  • 2.2 Decimal to binary conversion
  • 2.3 Conversion among binary, octal and hexadecimal
  • 2.4 Binary arithmetic (addition, subtraction)
  • 2.5 Signed number representation (1's and 2's complement)
  • 2.6 ASCII, Unicode, data representation in memory

Unit 3: Computer Software and Operating Systems (9 hrs)

  • 3.1 Software and its types
  • 3.2 System software, application software
  • 3.3 Operating system and its objectives
  • 3.4 Types of OS: batch, time-sharing, distributed, real-time
  • 3.5 Functions of OS: process and memory management
  • 3.6 CLI vs GUI
  • 3.7 File system basics; Windows, Linux, macOS

Unit 4: Computer Networks and Internet Basics (9 hrs)

  • 4.1 Introduction and importance of networking
  • 4.2 Data transmission media and data transmission
  • 4.3 Network types: LAN, WAN, MAN
  • 4.4 Topologies (star, bus, ring, mesh), communication protocol
  • 4.5 Network devices (hub, switch, router, modem, gateway), wireless networking
  • 4.6 Internet, IP address
  • 4.7 TCP, UDP, HTTP, FTP, DNS, URL, client-server architecture

Unit 5: Emerging Technologies (8 hrs)

  • 5.1 Internet of Things: concept, architecture, applications
  • 5.2 Cyber security: terminology, CIA triad, threats and countermeasures
  • 5.3 Artificial Intelligence: introduction, agents, applications
  • 5.4 Machine Learning: learning paradigms, applications
  • 5.5 Blockchain: distributed ledger, blocks, hashing, decentralization
  • 5.6 Data science: lifecycle, role of data in decision making
