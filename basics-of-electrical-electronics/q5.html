Assignment-1 · Question 5 (Sub-BEEE · Submission: 21/10/2026)

Explain the working of a Half wave Rectifier and derive the expression for average and RMS values of output voltage.

1. Principle & Circuit Diagram of a Half-Wave Rectifier (HWR)

A Half-Wave Rectifier (HWR) is an electronic circuit that converts bidirectional alternating current (AC) into unidirectional pulsating direct current (DC) by utilizing only one half-cycle of the input AC wave and blocking the other half-cycle using a single p-n junction diode.

2. Working Operation of Half-Wave Rectifier

Let the alternating voltage across the transformer secondary winding be vi = Vm sin(ωt):

  • During Positive Half-Cycle (0 < ωt < π): Terminal A is positive with respect to terminal B. The diode D becomes forward biased (ON) and conducts current through the load resistor RL. Hence, output voltage is vo = Vm sin(ωt) and load current is iL = Im sin(ωt), where Im = Vm / (Rf + RL) ≈ Vm / RL.
  • During Negative Half-Cycle (π < ωt < 2π): Terminal A is negative with respect to terminal B. The diode D becomes reverse biased (OFF) and acts as an open switch. Hence, no current flows through RL, so iL = 0 and vo = 0.

Thus, the output voltage across RL over one complete cycle (0 to 2π) is:

vo(ωt) = Vm sin(ωt)  for  0 ≤ ωt ≤ π ,    and    vo(ωt) = 0  for  π ≤ ωt ≤ 2π.

3. Derivation of Average (DC) and RMS Values of Output Voltage

(a) Derivation of Average (DC) Output Voltage — Vdc (or Vavg)

By definition, the average value of a periodic waveform over one full period T = 2π is:

Vdc = (1 / 2π) ∫02π vo d(ωt) = (1 / 2π) [ ∫0π Vm sin(ωt) d(ωt) + ∫π2π 0 · d(ωt) ]

Vdc = (Vm / 2π) [ −cos(ωt) ]0π = (Vm / 2π) [ −cos π − (−cos 0) ] = (Vm / 2π) [ −(−1) + 1 ] = (Vm / 2π) (2)

∴   Vdc = Vavg = Vm / π ≈ 0.318 Vm    (and Idc = Im / π ≈ 0.318 Im)

(b) Derivation of RMS (Root Mean Square) Output Voltage — Vrms

By definition, the RMS value over a full period 2π is:

Vrms = √[ (1 / 2π) ∫02π vo2 d(ωt) ] = √[ (1 / 2π) ∫0π Vm2 sin2(ωt) d(ωt) ]

Using the trigonometric identity sin2(ωt) = [ 1 − cos(2ωt) ] / 2:

Vrms2 = (Vm2 / 4π) ∫0π [ 1 − cos(2ωt) ] d(ωt) = (Vm2 / 4π) [ ωt − sin(2ωt)/2 ]0π = (Vm2 / 4π) (π − 0) = Vm2 / 4

Taking the square root on both sides:

∴   Vrms = Vm / 2 = 0.5 Vm    (and Irms = Im / 2 = 0.5 Im)

(c) Key Performance Parameters of HWR

  • Form Factor: F = Vrms / Vdc = (Vm/2) / (Vm/π) = π / 2 = 1.57
  • Ripple Factor: γ = √(F2 − 1) = √(1.572 − 1) = 1.21 (121%)
  • Maximum Rectification Efficiency: ηmax = Pdc / Pac = (Vm/π)2 / (Vm/2)2 = 4 / π2 = 40.6%
  • Peak Inverse Voltage (PIV): Vm
