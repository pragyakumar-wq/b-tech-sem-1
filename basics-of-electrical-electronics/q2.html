Assignment-1 · Question 2 (Sub-BEEE · Submission: 21/10/2026)

Describe the three configurations of BJT (CE, CB, CC) and their applications.

1. Overview of BJT Configurations

A Bipolar Junction Transistor (BJT) is a three-terminal device (Emitter E, Base B, Collector C), whereas an amplifier or circuit requires four terminals (two for input and two for output). Therefore, one of the three terminals is made common to both input and output signals, giving rise to three configurations:

  1. Common Base (CB) Configuration
  2. Common Emitter (CE) Configuration
  3. Common Collector (CC) / Emitter Follower Configuration

2. Neat Circuit Diagrams of CB, CE, and CC Configurations

3. Detailed Description & Current Gain Relations

  • 1. Common Base (CB) Configuration: The Base terminal is common to both input (applied between Emitter and Base) and output (taken between Collector and Base).
    • Current Amplification Factor (α): α = ΔIC / ΔIE (at constant VCB). Since IC < IE, α is always slightly less than 1 (typically 0.95 to 0.99).
    • Collector Current Equation: IC = α IE + ICBO.
  • 2. Common Emitter (CE) Configuration: The Emitter terminal is common to both input (applied between Base and Emitter) and output (taken between Collector and Emitter).
    • Base Current Amplification Factor (β): β = ΔIC / ΔIB (at constant VCE). Typically ranges from 50 to 300.
    • Relation between α and β: Since IE = IB + IC ⇒ ΔIE = ΔIB + ΔIC, dividing by ΔIC gives 1/α = 1/β + 1:
    β = α / (1 − α)    and    α = β / (β + 1).
    • Collector Current Equation: IC = β IB + (1 + β)ICBO = β IB + ICEO.
  • 3. Common Collector (CC) Configuration (Emitter Follower): The Collector terminal is grounded for AC signals; input is applied between Base and Collector and output is taken across Emitter and Collector.
    • Current Gain (γ): γ = ΔIE / ΔIB = 1 + β = 1 / (1 − α).
