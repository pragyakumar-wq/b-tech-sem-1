Assignment-1 · Question 6 (Sub-BEEE · Submission: 21/10/2026)

Explain the working of a Full wave Rectifier and derive the expression for average and RMS values of output voltage.

1. Principle & Circuit Diagrams of a Full-Wave Rectifier (FWR)

A Full-Wave Rectifier (FWR) converts both half-cycles (positive and negative) of an alternating current (AC) input signal into unidirectional pulsating DC current through the load resistor RL. There are two standard circuit configurations: (1) Center-Tapped Full-Wave Rectifier (2 diodes) and (2) Full-Wave Bridge Rectifier (4 diodes).

2. Working Operation of Full-Wave Rectifier

  • During Positive Half-Cycle (0 < ωt < π): Upper end A of the secondary winding is positive and lower end B is negative with respect to the Center Tap (CT). Diode D1 is forward biased (ON) while diode D2 is reverse biased (OFF). Current flows from A → D1 → RL → CT, giving output voltage vo = Vm sin(ωt). (In a Bridge Rectifier, diagonally opposite diodes D1 & D2 conduct).
  • During Negative Half-Cycle (π < ωt < 2π): Upper end A becomes negative and lower end B becomes positive with respect to CT. Now diode D1 is reverse biased (OFF) while diode D2 is forward biased (ON). Current flows from B → D2 → RL → CT in the exact same direction through RL! Thus vo = −Vm sin(ωt) = |Vm sin(ωt)| > 0. (In a Bridge Rectifier, diodes D3 & D4 conduct).

Since the output pulse repeats every π radians (half period), we integrate over 0 to π with period π.

3. Derivation of Average (DC) and RMS Values of Output Voltage

(a) Derivation of Average (DC) Output Voltage — Vdc (or Vavg)

Since the output waveform vo = Vm sin(ωt) repeats with period π:

Vdc = (1 / π) ∫0π Vm sin(ωt) d(ωt) = (Vm / π) [ −cos(ωt) ]0π = (Vm / π) [ −cos π − (−cos 0) ] = (Vm / π) [ 1 + 1 ]

∴   Vdc = Vavg = 2Vm / π ≈ 0.637 Vm    (and Idc = 2Im / π ≈ 0.637 Im)

(b) Derivation of RMS (Root Mean Square) Output Voltage — Vrms

Integrating the square of the output voltage over one period π:

Vrms = √[ (1 / π) ∫0π Vm2 sin2(ωt) d(ωt) ] = √[ (Vm2 / 2π) ∫0π (1 − cos 2ωt) d(ωt) ]

Vrms2 = (Vm2 / 2π) [ ωt − sin(2ωt)/2 ]0π = (Vm2 / 2π) (π − 0) = Vm2 / 2

Taking the square root on both sides:

∴   Vrms = Vm / √2 ≈ 0.707 Vm    (and Irms = Im / √2 ≈ 0.707 Im)

(c) Key Performance Parameters of FWR

  • Form Factor: F = Vrms / Vdc = (Vm/√2) / (2Vm/π) = π / (2√2) = 1.11
  • Ripple Factor: γ = √(F2 − 1) = √(1.112 − 1) = 0.482 (48.2%)
  • Maximum Rectification Efficiency: ηmax = Pdc / Pac = (2Vm/π)2 / (Vm/√2)2 = 8 / π2 = 81.2% (twice that of HWR)
  • Ripple Frequency: 2f (100 Hz for 50 Hz AC supply)
  • Peak Inverse Voltage (PIV): 2Vm (Center-Tapped) and Vm (Bridge Rectifier)
