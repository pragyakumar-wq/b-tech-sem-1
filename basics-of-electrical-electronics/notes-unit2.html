This unit covers AC signals, RMS/average values, waveform factors, phase and phasors, impedance, admittance, power factor, power triangle and three-phase systems.

2.1 Signals and Waveforms

An electrical signal is a time-varying voltage or current. Common waveforms are sinusoidal, square, triangular and saw-tooth. Sinusoidal AC is fundamental in power systems.

v(t)=Vₘ sin(ωt+φ),   ω=2πf,   T=1/f
  • Vₘ = peak value
  • ω = angular frequency
  • f = frequency in Hz
  • φ = phase angle

2.2 AC Quantities

Instantaneous and peak value

Instantaneous value is the value at a particular time; peak value is the maximum magnitude.

Average value

For a complete symmetrical sine cycle the average is zero. For a rectified sine wave:

Vavg=2Vₘ/π=0.637Vₘ

RMS value

RMS is the equivalent DC value producing the same heating effect in a resistor.

Vrms=Vₘ/√2=0.707Vₘ;   Irms=Iₘ/√2
For Vₘ=325 V, Vrms≈230 V.

2.3 Peak Factor and Form Factor

Peak factor=Maximum/RMS;   Form factor=RMS/Average

For a sine wave, peak factor=√2≈1.414 and form factor≈1.11 using the rectified average.

2.4 Phase and Phasors

If one sinusoid reaches its reference point earlier, it leads; the other lags. In-phase quantities have 0° phase difference; quadrature has 90°.

A phasor represents a sinusoidal quantity as a rotating vector.

Z=a+jb=|Z|∠θ;   |Z|=√(a²+b²), θ=tan⁻¹(b/a)

Rectangular and polar forms are both used in AC calculations.

2.6 Three-Phase Systems

A balanced three-phase system has three equal-magnitude sinusoidal quantities separated by 120°. It is widely used for generation, transmission and motors.

  • More economical power transmission.
  • Nearly constant power for balanced loads.
  • Three-phase motors are robust and self-starting.
Star: VL=√3Vph, IL=Iph
Delta: VL=Vph, IL=√3Iph
P=√3VLILcosφ

Phase sequence is the order in which phase quantities reach their positive maxima. Balanced loads have symmetrical phase impedances; unbalanced loads do not.
