2.1 & 2.2 Alternating Signals, Instantaneous, Peak, Average & RMS Values (TSO 2a)

An alternating voltage or current varies periodically in both magnitude and direction with time. A standard sinusoidal alternating voltage is expressed as:

v(t) = Vm sin(ωt + φ) ,    where    ω = 2πf = 2π / T  (rad/s)

  • Instantaneous Value v(t) or i(t): The value of the alternating quantity at any specific instant of time t.
  • Peak Value (Maximum Value / Amplitude Vm or Im): The highest positive or negative value attained during a half-cycle. (Peak-to-peak value Vp-p = 2Vm).
  • Time Period (T): Time taken (in seconds) to complete one full cycle (T = 1/f; for India's 50 Hz grid, T = 1/50 = 0.02 s = 20 ms).

Derivations of Average Value and RMS Value of a Sinusoidal AC Wave

1. Average Value (Iavg or Vavg)

Definition: The steady DC current which transfers the same electric charge across a circuit in the same time as the alternating current over a half-cycle (since full-cycle average of a symmetrical sine wave is zero):

Iavg = (1 / π) ∫0π Im sin θ dθ = (Im / π) [ −cos θ ]0π

∴   Iavg = 2Im / π = 0.637 Im    (Vavg = 0.637 Vm)

2. RMS / Effective / Virtual Value (Irms or Vrms)

Definition: The steady DC current which produces the same heating effect (I2Rt) in a given resistor in the same time as the alternating current over one complete cycle:

Irms = √[ (1 / 2π) ∫02π Im2 sin2 θ dθ ] = √[ (Im2 / 4π) ∫02π (1 − cos 2θ) dθ ]

∴   Irms = Im / √2 = 0.707 Im    (Vrms = 0.707 Vm)

2.3 Waveform Factors: Form Factor & Peak (Crest) Factor

  • 1. Form Factor (Kf): Ratio of RMS value to Average value of an alternating wave:
    Form Factor (Kf) = RMS Value / Average Value = (Vm / √2) / (2Vm / π) = π / (2√2) = 1.11.
  • 2. Peak Factor / Crest Factor / Amplitude Factor (Kp): Ratio of Maximum (Peak) value to RMS value:
    Peak Factor (Kp) = Maximum Value / RMS Value = Vm / (Vm / √2) = √2 = 1.414.

2.4 Phase, Phasor Representation & Rectangular / Polar Forms (TSO 2b)

  • Phase Difference (φ): If v(t) = Vm sin(ωt + φ1) and i(t) = Im sin(ωt + φ2), then φ = φ1 − φ2 is the phase difference:
    • In-Phase (φ = 0°): Both reach zero and peak values simultaneously (Purely resistive circuit).
    • Leading / Lagging: The quantity that reaches its peak value earlier in time is said to lead the other, while the second lags behind.
  • Phasor Representation (Rectangular ⟷ Polar Conversion):
    A sinusoidal quantity is represented by a rotating vector (phasor) using RMS magnitude:
    Polar Form: Z = |Z| ∠ θ    ⟷    Rectangular Form: Z = R + jX = |Z|(cos θ + j sin θ)
    where |Z| = √(R2 + X2) and θ = tan−1(X / R).

Power Triangle & Three Types of AC Power:

  • 1. Active / True / Real Power (P): Actual useful power consumed in the circuit: P = V I cos φ = I2R  (Unit: Watts, W or kW).
  • 2. Reactive / Quadrature Power (Q): Power oscillating back and forth in magnetic/electric fields: Q = V I sin φ = I2X  (Unit: Volt-Ampere Reactive, VAR or kVAR).
  • 3. Apparent Power (S): Product of RMS voltage and RMS current: S = V I = I2|Z| = √(P2 + Q2)  (Unit: Volt-Ampere, VA or kVA).
  • Power Factor (cos φ): cos φ = P / S = R / |Z|. Low lagging power factor increases line current (I = P / (V cos φ)) and causes higher I2R line losses; it is improved by connecting static capacitors in parallel with inductive loads.

2.6 Three-Phase AC Systems: Star (Y) and Delta (Δ) Connections (TSO 2d)

A balanced three-phase system consists of three equal-magnitude sinusoidal EMFs displaced from each other by 120° electrical (Phase Sequence R-Y-B):

eR = Em sin(ωt) ,    eY = Em sin(ωt − 120°) ,    eB = Em sin(ωt − 240°) = Em sin(ωt + 120°)

Advantages over Single-Phase: (1) Requires ~25% less conductor material to transmit the same power, (2) Produces a uniform rotating magnetic field making 3-phase induction motors self-starting, (3) Instantaneous power is constant (smooth torque), (4) Star connection provides two voltages (400 V line, 230 V phase).
