Question 3

What is a State-Space Search Problem? Explain BFS, DFS, UCS, Depth-Limited Search and Iterative Deepening Search. Compare their completeness and optimality.

State-Space Search Problem

A state-space search problem represents a problem as a collection of possible states and actions that move the system from one state to another.

A search problem generally contains:

  1. Initial State – The state from which the problem starts.
  2. Actions/Operators – The possible actions available.
  3. Transition Model – Describes the result of applying an action.
  4. Goal State/Test – Determines whether the desired state has been reached.
  5. Path Cost – The cost of reaching a state from the initial state.

Example: In a route-finding problem, cities can be considered states and roads can be considered actions.

1. Breadth First Search (BFS)

BFS explores nodes level by level. It first explores all nodes at depth 1, then depth 2, and so on.

It uses a FIFO (First-In, First-Out) queue.

Working:

  1. Start from the initial node.
  2. Add its children to a queue.
  3. Remove the first node from the queue.
  4. Expand it and add its unvisited children.
  5. Continue until the goal is found.

Advantages:

  • Complete when the branching factor is finite.
  • Optimal when all step costs are equal.

Disadvantage: Requires large memory.

2. Depth First Search (DFS)

DFS explores the deepest node first before backtracking.

It uses a stack or recursion.

Working:

  1. Start from the initial node.
  2. Select one child.
  3. Continue deeper until a leaf or dead end is reached.
  4. Backtrack and explore another branch.

Advantages:

  • Requires less memory than BFS.
  • Can find a solution quickly if the correct path is explored early.

Disadvantage: May get stuck exploring a very deep or infinite path.

3. Uniform Cost Search (UCS)

UCS expands the node with the lowest path cost from the initial state.

It uses a priority queue.

If the path costs are:

  • A → B = 2
  • A → C = 5
  • A → D = 3

UCS will select B first because its path cost is lowest.

Advantage: UCS is optimal when step costs are positive.

4. Depth-Limited Search (DLS)

Depth-Limited Search is a modified version of DFS in which a maximum depth limit is specified.

For example, if the depth limit is 3, the algorithm does not explore nodes beyond depth 3.

Advantage: Prevents infinite exploration.

Disadvantage: It may fail to find a solution located beyond the depth limit.

5. Iterative Deepening Search (IDS)

Iterative Deepening Search repeatedly performs Depth-Limited Search with increasing depth limits.

For example: Limit 0 → Limit 1 → Limit 2 → Limit 3 → ...

It combines some advantages of BFS and DFS.

Advantages:

  • Complete for finite branching factor.
  • Optimal when all step costs are equal.
  • Uses relatively low memory.

Conclusion

State-space search provides a systematic way of solving AI problems. BFS, DFS, UCS, DLS, and IDS are important uninformed search techniques because they do not use domain-specific heuristic information.
