Unit 4 · 7 hrs

Reasoning Under Uncertainty

Syllabus topics:

  • Sources of uncertainty, basic probability
  • Bayes' theorem
  • Bayesian networks
  • Fuzzy logic and fuzzy sets
  • Certainty factors and rule-based uncertainty

Need for probabilistic reasoning

  • Real agents have incomplete or noisy information: sensor errors, partial observability, unpredictable events.
  • Logic gives only true or false. Probability gives a degree of belief between 0 and 1.
  • Basic rules: 0 ≤ P(A) ≤ 1, P(A) + P(¬A) = 1, P(A|B) = P(A ∧ B) / P(B).

Bayes' theorem

P(H|E) = P(E|H) × P(H) / P(E)

H = hypothesis, E = evidence, P(H) = prior, P(E|H) = likelihood, P(H|E) = posterior. P(E) = P(E|H)P(H) + P(E|¬H)P(¬H).

Example: P(disease) = 0.01, P(positive | disease) = 0.9, P(positive | no disease) = 0.05. P(positive) = 0.9×0.01 + 0.05×0.99 = 0.0585. P(disease | positive) = 0.009 / 0.0585 ≈ 0.154, about 15.4%.

Bayesian networks

  • A directed acyclic graph: each node is a random variable, each arrow shows direct influence.
  • Each node has a conditional probability table (CPT) given its parents.
  • Joint probability = product of P(Xi | parents(Xi)).
  • Classic example: Burglary and Earthquake → Alarm → JohnCalls, MaryCalls.
  • Steps to construct: choose variables, add arrows for direct causes, fill CPTs, then compute queries by multiplying and summing probabilities.

Fuzzy logic and fuzzy sets

In a crisp set an element is in or out. In a fuzzy set each element has a membership value μ(x) between 0 and 1 (example: "tall", "warm").

OperationFormula
UnionμA∪B(x) = max(μA(x), μB(x))
IntersectionμA∩B(x) = min(μA(x), μB(x))
ComplementμA'(x) = 1 − μA(x)

Fuzzy control steps: fuzzification, rule evaluation, aggregation, defuzzification (example: washing machine, air conditioner).

Certainty factors

  • A certainty factor (CF) ranges from −1 (certainly false) to +1 (certainly true). Used in rule-based systems such as MYCIN.
  • Rule CF: CF(conclusion) = CF(rule) × CF(evidence).
  • Two rules supporting the same conclusion (both positive): CF = CF1 + CF2 × (1 − CF1).
