Question 4

Explain informed search techniques. Discuss Greedy Best-First Search and A* Search with a suitable example. Also explain the role of the heuristic function in A* Search.

Informed Search

Informed search, also called heuristic search, uses additional knowledge about the problem to guide the search toward the goal.

This additional knowledge is represented by a heuristic function h(n).

A heuristic function estimates the cost of reaching the goal from the current node.

Example: In a road map, the straight-line distance between a city and the destination can be used as a heuristic.

Greedy Best-First Search

Greedy Best-First Search selects the node that appears to be closest to the goal.

It uses the evaluation function:

f(n) = h(n)

where h(n) = estimated cost from node n to the goal.

The algorithm always chooses the node with the smallest heuristic value.

Example

Suppose a route search has the following estimated distances to the goal:

Nodeh(n)
A10
B6
C4
D2
Goal0

Greedy Best-First Search will generally prefer the node with the smallest h(n).

Advantages:

  • Often faster than uninformed search.
  • Can quickly reach the goal when the heuristic is good.

Disadvantages:

  • Not always optimal.
  • Can be misled by an inaccurate heuristic.
  • May not be complete in some search spaces.

A* Search

A* is one of the most important informed search algorithms. It combines the actual cost of reaching a node with an estimate of the remaining cost.

Its evaluation function is:

f(n) = g(n) + h(n)

where:

  • g(n) = actual cost from the initial state to node n.
  • h(n) = estimated cost from node n to the goal.
  • f(n) = estimated total cost of a solution through node n.

Suitable Example

Suppose there are two possible nodes:

Nodeg(n)h(n)f(n) = g(n)+h(n)
A4610
B729

A* will select B because its total estimated cost is smaller:

f(B) = 7 + 2 = 9
while
f(A) = 4 + 6 = 10

Therefore, A* considers both the cost already spent and the estimated cost remaining.

Role of Heuristic Function in A* Search

The heuristic function h(n) is very important because it helps A* decide which nodes are more promising.

A good heuristic:

  • Guides the search toward the goal.
  • Reduces unnecessary exploration.
  • Can make the search much faster.
  • Provides an estimate of the remaining cost.

For A* to guarantee an optimal solution under the standard conditions, the heuristic should be admissible, meaning it never overestimates the actual minimum cost from node n to the goal.

Example: In a road-navigation problem, the straight-line distance between two locations is often an admissible heuristic when road distance cannot be shorter than the straight-line distance.

Conclusion

Informed search techniques use heuristic knowledge to improve search efficiency. Greedy Best-First Search focuses mainly on the estimated distance to the goal, while A* considers both the actual path cost and the estimated remaining cost. Therefore, A* is generally more reliable when an appropriate heuristic is available.
