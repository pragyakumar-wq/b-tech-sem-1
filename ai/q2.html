Question 2

What is an Intelligent Agent? Explain the PEAS framework with a suitable example. Also differentiate between simple reflex, model-based, goal-based, utility-based and learning agents.

Intelligent Agent

An intelligent agent is a system that perceives its environment through sensors and acts upon that environment through actuators to achieve a particular objective.

The basic working of an agent is:

Environment → Sensors → Agent → Actuators → Environment

Example: A self-driving car uses cameras and other sensors to observe roads and traffic and uses steering, brakes, and acceleration to act.

PEAS Framework

PEAS stands for:

  • P – Performance Measure
  • E – Environment
  • A – Actuators
  • S – Sensors

PEAS is used to describe the task environment of an intelligent agent.

Example: Self-Driving Car

PEAS ComponentDescription
Performance MeasureSafety, reaching destination, minimum travel time, passenger comfort
EnvironmentRoads, traffic, pedestrians, traffic signals, weather
ActuatorsSteering, brakes, accelerator, horn
SensorsCameras, GPS, radar, ultrasonic sensors

Thus, PEAS provides a clear description of what an intelligent agent needs to observe, how it acts, and how its performance is evaluated.

Types of Intelligent Agents

  1. 1. Simple Reflex AgentA simple reflex agent selects an action based only on the current percept.
    Rule: "If condition occurs → perform action."
    Example: A thermostat turns the heater ON when the temperature becomes too low.
    Limitation: It does not remember previous situations.
  2. 2. Model-Based AgentA model-based agent maintains an internal model or internal state of the environment. It uses previous information along with the current percept.
    Example: A robot remembers the locations it has already visited while navigating a room.
  3. 3. Goal-Based AgentA goal-based agent selects actions that help it achieve a specific goal.
    Example: A navigation system chooses a route to reach a particular destination.
  4. 4. Utility-Based AgentA utility-based agent chooses an action based on how useful or desirable the resulting state is.
    Example: A navigation system may choose a route that balances travel time, distance, safety, and traffic.
  5. 5. Learning AgentA learning agent improves its performance by learning from experience and feedback.
    A learning agent generally consists of:
    • Learning element
    • Performance element
    • Critic
    • Problem generator
    Example: A recommendation system learns from a user's previous choices and improves its future recommendations.

Conclusion

Intelligent agents are an important concept in AI because they allow systems to perceive their environment, make decisions, and perform actions. Different agent types provide increasing levels of intelligence and adaptability.
