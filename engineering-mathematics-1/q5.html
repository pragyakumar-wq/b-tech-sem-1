Question 5 · Unit 5 (CO5)

Define Gradient, Divergence, and Curl with physical significance. Prove that ∇ · (rn r) = (n + 3)rn and ∇ × (rn r) = 0. Also state Green's, Stokes', and Gauss' Divergence Theorems and verify Green's Theorem for ∮C [(xy + y2)dx + x2 dy] bounded by y = x and y = x2.

Part A: Proofs of Vector Identities for rn r

Let r = x i + y j + z k so that r2 = x2 + y2 + z2 and ∂r/∂x = x/r,  ∂r/∂y = y/r,  ∂r/∂z = z/r.

1. Proof that ∇ · (rn r) = (n + 3)rn:
Since rn r = (rn x)i + (rn y)j + (rn z)k:
∂(rn x)/∂x = rn(1) + x · n rn−1 (∂r/∂x) = rn + n rn−2 x2.
Summing over x, y, z:
∇ · (rn r) = 3 rn + n rn−2(x2 + y2 + z2) = 3 rn + n rn−2 r2 = (n + 3) rn.
Corollary: rn r is solenoidal (∇ · (rn r) = 0) if and only if n = −3 (i.e., the inverse-square field r / r3).

2. Proof that ∇ × (rn r) = 0 (Irrotational for all n):
The i-component of ∇ × (rn r) is:
∂(rn z)/∂y − ∂(rn y)/∂z = z · n rn−1(y/r) − y · n rn−1(z/r) = n rn−2 yz − n rn−2 yz = 0.
By symmetry, the j- and k-components are also 0. Hence ∇ × (rn r) = 0.

Part B: Verification of Green's Theorem in the Plane

Problem: Verify Green's Theorem ∮C (M dx + N dy) = ∬R (∂N/∂x − ∂M/∂y) dx dy for M = xy + y2 and N = x2, where C is the closed curve bounded by y = x2 and y = x (intersecting at (0,0) and (1,1)).

  1. 1. Evaluation of Double Integral (RHS):
    Here ∂N/∂x = 2x and ∂M/∂y = x + 2y, so ∂N/∂x − ∂M/∂y = 2x − (x + 2y) = x − 2y.
    RHS = ∫x=01 ∫y=x2x (x − 2y) dy dx = ∫01 [ xy − y2 ]x2x dx = ∫01 (x4 − x3) dx = [ x5/5 − x4/4 ]01 = 1/5 − 1/4 = −1 / 20.
  2. 2. Evaluation of Closed Line Integral (LHS = I1 + I2):
    • Along C1 (parabola y = x2, dy = 2x dx from x = 0 to x = 1):
    I1 = ∫01 [ (x3 + x4)dx + x2(2x dx) ] = ∫01 (3x3 + x4) dx = 3/4 + 1/5 = 19 / 20.
    • Along C2 (line y = x, dy = dx from x = 1 to x = 0):
    I2 = ∫10 [ (x2 + x2)dx + x2 dx ] = ∫10 3x2 dx = [ x3 ]10 = −1.
    • Total LHS = I1 + I2 = 19/20 − 1 = −1 / 20.
    Since LHS = RHS = −1/20, Green's Theorem is verified!
