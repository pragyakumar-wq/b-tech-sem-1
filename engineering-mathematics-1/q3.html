Question 3 · Unit 3 (CO3)

State Euler's Theorem on homogeneous functions. If u = tan−1[(x3 + y3)/(x − y)], prove that x ux + y uy = sin 2u and x2 uxx + 2xy uxy + y2 uyy = sin 4u − sin 2u. Also find extreme values using Lagrange's Multiplier Method.

Part A: Euler's Theorem Proof & Application

Euler's Theorem Statement: If z = f(x, y) is a homogeneous function of degree n (meaning f(tx, ty) = tn f(x, y)), then:

x (∂z/∂x) + y (∂z/∂y) = n z ,    and    x2(∂2z/∂x2) + 2xy(∂2z/∂x∂y) + y2(∂2z/∂y2) = n(n − 1)z.

Solution for u = tan−1[(x3 + y3)/(x − y)]:

  1. Rewrite as z = tan u = (x3 + y3) / (x − y).
  2. Test homogeneity of z: z(tx, ty) = t3(x3 + y3) / [t(x − y)] = t2 z(x, y).
    Hence z = tan u is a homogeneous function of x and y of degree n = 2.
  3. Applying Euler's First-Order Theorem to z = tan u:
    x (∂/∂x)(tan u) + y (∂/∂y)(tan u) = 2 tan u
    sec2 u [ x(∂u/∂x) + y(∂u/∂y) ] = 2 tan u
    x (∂u/∂x) + y (∂u/∂y) = 2 tan u / sec2 u = 2 sin u cos u = sin 2u = g(u). (First Result Proved!)
  4. Applying the Second-Order Deduction with g(u) = sin 2u and g'(u) = 2 cos 2u:
    x2 uxx + 2xy uxy + y2 uyy = g(u) [ g'(u) − 1 ] = sin 2u (2 cos 2u − 1) = 2 sin 2u cos 2u − sin 2u = sin 4u − sin 2u. (Second Result Proved!)

Part B: Constrained Optimization Using Lagrange's Multiplier Method

Problem: Find the minimum value of f(x, y, z) = x2 + y2 + z2 subject to the plane constraint ax + by + cz = p.

Solution:

  1. Form Lagrangian: F(x, y, z, λ) = (x2 + y2 + z2) + λ(ax + by + cz − p).
  2. Set partial derivatives to zero:
    • ∂F/∂x = 2x + λa = 0 ⇒ x = −λa / 2
    • ∂F/∂y = 2y + λb = 0 ⇒ y = −λb / 2
    • ∂F/∂z = 2z + λc = 0 ⇒ z = −λc / 2
  3. Substitute into constraint ax + by + cz = p:
    −(λ/2)(a2 + b2 + c2) = p ⇒ −λ/2 = p / (a2 + b2 + c2).
  4. Hence x = ap/(a2+b2+c2), y = bp/(a2+b2+c2), z = cp/(a2+b2+c2), giving the minimum value:
    fmin = x2 + y2 + z2 = p2 / (a2 + b2 + c2).
