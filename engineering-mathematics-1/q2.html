Question 2 · Unit 2 (CO2)

State Leibnitz's Theorem. If y = (sin−1 x)2, prove that (1 − x2)yn+2 − (2n + 1)x yn+1 − n2 yn = 0 and find yn(0). Also state and compare Rolle's, Lagrange's, and Cauchy's Mean Value Theorems.

Part A: Leibnitz's Theorem & Derivation for y = (sin−1 x)2

Leibnitz's Theorem Statement: If u(x) and v(x) possess derivatives up to the nth order, then:

Dn(uv) = unv + nC1 un−1v1 + nC2 un−2v2 + … + u vn

Derivation for y = (sin−1 x)2:

  1. Differentiate wrt x: y1 = 2(sin−1 x) / √(1 − x2).
    Squaring both sides: (1 − x2) y12 = 4(sin−1 x)2 = 4y.
  2. Differentiate again wrt x: (1 − x2)(2y1y2) − 2x y12 = 4y1.
    Dividing by 2y1 gives: (1 − x2)y2 − x y1 − 2 = 0   … (Equation 1).
  3. Differentiate Equation 1 n times using Leibnitz's Theorem:
    [ (1 − x2)yn+2 + n(−2x)yn+1 + (n(n−1)/2)(−2)yn ] − [ x yn+1 + n(1)yn ] = 0
    Simplifying gives: (1 − x2)yn+2 − (2n + 1)x yn+1 − n2 yn = 0   … (Equation 2).
  4. Finding yn(0): Substitute x = 0 into the relations:
    • y(0) = 0,  y1(0) = 0,  y2(0) = 2.
    • From Equation 2 at x = 0: yn+2(0) = n2 yn(0).
    • If n is odd: since y1(0) = 0, we get y3(0) = y5(0) = … = 0.
    • If n is even (n = 2, 4, 6, …): y2(0) = 2, y4(0) = 22 · 2, y6(0) = 42 · 22 · 2, and in general:
    yn(0) = 2 · 22 · 42 · 62 … (n − 2)2.
