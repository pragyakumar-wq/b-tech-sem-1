2.1 Successive Differentiation & Leibnitz's Theorem (TSO 2a)

The process of differentiating a function y = f(x) repeatedly with respect to x is called successive differentiation. The successive derivatives are denoted by y1, y2, y3, …, yn or D y, D2y, …, Dny.

Leibnitz's Theorem for the nth Derivative of a Product

Statement: If u and v are two functions of x possessing derivatives up to the nth order, then the nth derivative of their product (uv) is given by:

(uv)n = unv + nC1 un−1v1 + nC2 un−2v2 + … + nCr un−rvr + … + u vn

Practical Rule: Choose v as the algebraic polynomial (like x2 or 1 − x2) so that its higher derivatives vanish after 2 or 3 terms!

Solved Example 2.1: Leibnitz's Theorem & Finding yn(0)

Problem: If y = sin(m sin−1 x), prove that (1 − x2)y2 − x y1 + m2 y = 0, and hence prove by Leibnitz's theorem that (1 − x2)yn+2 − (2n + 1)x yn+1 − (n2 − m2)yn = 0.

Solution:

  1. Differentiate y = sin(m sin−1 x) with respect to x:
    y1 = cos(m sin−1 x) · [ m / √(1 − x2) ] ⇒ √(1 − x2) y1 = m cos(m sin−1 x).
    Squaring both sides: (1 − x2) y12 = m2 cos2(m sin−1 x) = m2 (1 − y2).
  2. Differentiate again with respect to x:
    (1 − x2)(2 y1 y2) + y12(−2x) = −2 m2 y y1.
    Dividing throughout by 2y1 gives: (1 − x2)y2 − x y1 + m2y = 0.
  3. Apply Leibnitz's Theorem to differentiate each term n times:
    • Dn[(1 − x2)y2] = yn+2(1 − x2) + n yn+1(−2x) + [n(n − 1)/2] yn(−2)
    • Dn[−x y1] = −[ yn+1(x) + n yn(1) ]
    • Dn[m2 y] = m2 yn
  4. Combine like terms:
    (1 − x2)yn+2 − (2n + 1)x yn+1 − (n2 − n + n − m2)yn = 0
    (1 − x2)yn+2 − (2n + 1)x yn+1 − (n2 − m2)yn = 0. (Hence Proved!)

Solved Example 2.2: Inequality Proof Using Lagrange's Mean Value Theorem

Problem: Using Lagrange's Mean Value Theorem, prove that x / (1 + x) < log(1 + x) < x for all x > 0.

Solution: Let f(t) = log(1 + t) on the interval [0, x] for x > 0. Since f(t) is continuous on [0, x] and differentiable on (0, x) with f'(t) = 1 / (1 + t), by LMVT there exists c ∈ (0, x) such that:

[ log(1 + x) − log(1 + 0) ] / (x − 0) = f'(c) = 1 / (1 + c)   ⇒   log(1 + x) / x = 1 / (1 + c)

Since 0 < c < x, we have 1 < 1 + c < 1 + x. Taking reciprocals reverses the inequalities:

1 / (1 + x) < 1 / (1 + c) < 1   ⇒   1 / (1 + x) < log(1 + x) / x < 1

Multiplying throughout by x > 0 gives: x / (1 + x) < log(1 + x) < x. (Hence Proved!)

2.3 Indeterminate Forms & L'Hospital's Rule (TSO 2c)

When evaluating limx→a F(x) yields one of the seven indeterminate forms: 0/0,  ∞/∞,  0 × ∞,  ∞ − ∞,  00,  ∞0,  1∞, we reduce the expression to 0/0 or ∞/∞ and apply L'Hospital's Rule:

L'Hospital's Rule: If limx→a f(x)/g(x) is of the form 0/0 or ∞/∞, then:

limx→a [ f(x) / g(x) ] = limx→a [ f'(x) / g'(x) ]  (provided the latter limit exists).

  • Form 0 × ∞: Rewrite f(x) · g(x) as f(x) / [1/g(x)] (0/0) or g(x) / [1/f(x)] (∞/∞).
  • Form ∞ − ∞: Combine fractions by taking a common denominator or rationalizing to get 0/0.
  • Exponential Forms (00, ∞0, 1∞): For y = [f(x)]g(x), take natural log: log y = g(x) log f(x) = [log f(x)] / [1/g(x)]. If lim (log y) = L, then the required limit is eL.
    Shortcut for 1∞ form: If limx→a f(x) = 1 and limx→a g(x) = ∞, then limx→a [f(x)]g(x) = exp( limx→a g(x) [f(x) − 1] ).

Solved Example 2.3: L'Hospital's Rule

Problem: Evaluate L = limx→0 [ (tan x) / x ]1 / x2.

Solution: As x → 0, (tan x)/x → 1 and 1/x2 → ∞, so this is the 1∞ indeterminate form.
Taking logarithms and using standard Maclaurin expansion tan x = x + x3/3 + 2x5/15 + … (or repeated L'Hospital's Rule):

log L = limx→0 [ log((tan x)/x) ] / x2 = limx→0 [ (tan x / x) − 1 ] / x2 = limx→0 [ (x + x3/3 + … − x) / x3 ] = 1/3.

Hence, L = e1/3.

2.4 Tangents, Normals & Curvature (TSO 2d)

1. Tangents and Normals of Algebraic (Cartesian) & Polar Curves

Cartesian Curve y = f(x) at Point P(x1, y1)

  • Slope of Tangent: m = (dy/dx)(x1, y1) = tan ψ
  • Equation of Tangent: y − y1 = m (x − x1)
  • Equation of Normal: y − y1 = (−1/m) (x − x1)
  • Length of Subtangent: |y1 / m|
  • Length of Subnormal: |y1 · m|

Polar Curve r = f(θ)

  • Angle φ between radius vector OP and tangent:
    tan φ = r (dθ / dr)  or  cot φ = (1/r)(dr/dθ)
  • Angle between two polar curves at intersection:
    tan α = | (tan φ1 − tan φ2) / (1 + tan φ1 tan φ2) |
  • Pedal Equation (p-r relation): p = r sin φ and 1/p2 = 1/r2 + (1/r4)(dr/dθ)2.

2. Curvature (κ) and Radius of Curvature (ρ) (TSO 2d)

The curvature κ = |dψ / ds| measures the rate of bending of a curve at a point. Its reciprocal ρ = 1 / κ = |ds / dψ| is the Radius of Curvature.

Centre of Curvature (X̄, Ȳ) and Circle of Curvature: For a Cartesian curve y = f(x) at point (x, y):

X̄ = x − [ y1 (1 + y12) ] / y2 ,    Ȳ = y + [ 1 + y12 ] / y2

The locus of the centre of curvature (X̄, Ȳ) is called the Evolute of the curve, and the circle (X − X̄)2 + (Y − Ȳ)2 = ρ2 is the Circle of Curvature.

Solved Example 2.4: Radius of Curvature of a Polar Curve (Cardioid)

Problem: Find the radius of curvature at any point (r, θ) on the cardioid r = a(1 + cos θ) and prove that ρ2 / r is constant.

Solution:

  1. Differentiate r = a(1 + cos θ) with respect to θ:
    r1 = dr/dθ = −a sin θ,   r2 = d2r/dθ2 = −a cos θ.
  2. Compute r2 + r12:
    r2 + r12 = a2(1 + cos θ)2 + a2 sin2 θ = a2(1 + 2 cos θ + cos2 θ + sin2 θ) = 2a2(1 + cos θ) = 4a2 cos2(θ/2).
  3. Compute r2 + 2r12 − r r2:
    = a2(1 + cos θ)2 + 2a2 sin2 θ − a(1 + cos θ)(−a cos θ) = 3a2(1 + cos θ) = 6a2 cos2(θ/2).
  4. Substitute into the polar radius of curvature formula:
    ρ = [ 4a2 cos2(θ/2) ]3/2 / [ 6a2 cos2(θ/2) ] = [ 8a3 cos3(θ/2) ] / [ 6a2 cos2(θ/2) ] = (4a / 3) cos(θ/2).
  5. Since r = a(1 + cos θ) = 2a cos2(θ/2), we have cos2(θ/2) = r / (2a). Squaring ρ:
    ρ2 = (16a2 / 9) cos2(θ/2) = (16a2 / 9) · (r / 2a) = (8a / 9) r   ⇒   ρ2 / r = 8a / 9 = Constant. (Hence Proved!)
