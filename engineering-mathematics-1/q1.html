Question 1 · Unit 1 (CO1)

Find the rank of a matrix using Row Echelon Form, state Rouche's Theorem for consistency of linear equations, and verify the Cayley-Hamilton Theorem for A = [2 −1 1; −1 2 −1; 1 −1 2] to find A−1 and A4.

Part A: Rank of a Matrix & Rouche's Consistency Theorem

1. Rank of a Matrix ρ(A): The rank of an m × n matrix A is the order r of its largest non-vanishing minor, or equivalently the number of non-zero rows when A is reduced to Row Echelon Form (REF) via elementary row transformations.

2. Rouche's Theorem for Linear System AX = B (n unknowns):

  • If ρ(A) ≠ ρ([A | B]): The system is inconsistent and has no solution.
  • If ρ(A) = ρ([A | B]) = n: The system is consistent and has a unique solution.
  • If ρ(A) = ρ([A | B]) = r < n: The system is consistent and has infinitely many solutions involving (n − r) independent arbitrary parameters.

Part B: Verification of Cayley-Hamilton Theorem & Finding A−1 and A4

Given Matrix:

A = [  2  -1   1 ]
    [ -1   2  -1 ]
    [  1  -1   2 ]

Step 1 — Characteristic Equation |A − λI| = 0:
For a 3 × 3 matrix, the characteristic equation is λ3 − S1λ2 + S2λ − |A| = 0:

  • S1 = Trace(A) = 2 + 2 + 2 = 6
  • S2 = Sum of principal minors = (4 − 1) + (4 − 1) + (4 − 1) = 3 + 3 + 3 = 9
  • |A| = Determinant of A = 2(4 − 1) − (−1)(−2 + 1) + 1(1 − 2) = 6 − 1 − 1 = 4

Hence, the characteristic equation is: λ3 − 6λ2 + 9λ − 4 = 0.

Step 2 — Verification of Cayley-Hamilton Theorem:
We must show that A3 − 6A2 + 9A − 4I = 0:

A² = A · A = [  6  -5   5 ]      A³ = A² · A = [  22  -21   21 ]
             [ -5   6  -5 ]                    [ -21   22  -21 ]
             [  5  -5   6 ]                    [  21  -21   22 ]

Substituting into A3 − 6A2 + 9A − 4I:
• Diagonal entries: 22 − 6(6) + 9(2) − 4(1) = 22 − 36 + 18 − 4 = 0.
• Off-diagonal (±) entries: ±(21 − 6(5) + 9(1) − 0) = ±(21 − 30 + 9) = 0.
Thus A3 − 6A2 + 9A − 4I = 03×3, verifying the Cayley-Hamilton Theorem.

Step 3 — Finding A−1: Multiply A3 − 6A2 + 9A − 4I = 0 by A−1:
4I = A2 − 6A + 9A · A−1   ⇒   A−1 = (1/4) [ A2 − 6A + 9I ]

A⁻¹ = (1/4) [  3   1  -1 ]
            [  1   3   1 ]
            [ -1   1   3 ]

Step 4 — Finding A4: From A3 = 6A2 − 9A + 4I, multiply by A:
A4 = 6A3 − 9A2 + 4A = 6(6A2 − 9A + 4I) − 9A2 + 4A = 27A2 − 50A + 24I:

A⁴ = [  86  -85   85 ]
     [ -85   86  -85 ]
     [  85  -85   86 ]
