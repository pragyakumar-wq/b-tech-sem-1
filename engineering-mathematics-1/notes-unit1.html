1.1 Elementary Transformations & Rank of a Matrix

Elementary Row / Column Operations: Any of the following three operations on a matrix A produces an equivalent matrix (denoted A ~ B) having the exact same rank:

  • Interchange: Swapping two rows or two columns (Ri ↔ Rj or Ci ↔ Cj).
  • Scaling: Multiplying all elements of a row or column by a non-zero scalar k ≠ 0 (Ri → kRi).
  • Linear Combination: Adding to the elements of a row (or column) a scalar multiple of the corresponding elements of another row (or column) (Ri → Ri + kRj).

Definition of Rank of a Matrix — ρ(A)

A non-negative integer r is called the rank of an m × n matrix A, denoted by ρ(A) = r, if:

  1. There exists at least one non-zero minor of order r (i.e., determinant of an r × r submatrix ≠ 0).
  2. Every minor of order (r + 1) and higher (if any exist) is strictly zero.

Key Properties: For an m × n matrix A, 0 ≤ ρ(A) ≤ min(m, n). Rank of a null matrix is 0; rank of an identity matrix In is n; for a non-singular square matrix of order n (|A| ≠ 0), ρ(A) = n.

Methods to Find the Rank of a Matrix (TSO 1a)

MethodStructure / ConditionsHow Rank is Determined
1. Minor / Determinant MethodCompute determinants of square submatrices starting from the largest possible order.Largest order r for which at least one minor is non-zero. Best for small 3 × 3 matrices.
2. Row Echelon Form (REF)Uses only row operations:
• All zero rows are at the bottom.
• The leading non-zero entry (pivot) of each row lies strictly to the right of the pivot of the row above it.		ρ(A) = Number of non-zero rows in Row Echelon Form.
3. Normal Form (Canonical Form)Uses both row and column operations to reduce A into one of the four block forms:
[ Ir   0 ; 0   0 ],  [ Ir   0 ],  [ Ir ; 0 ], or [ Ir ].		ρ(A) = r, where Ir is the identity matrix of order r.
4. PAQ FormFind non-singular matrices P (via row ops on Im) and Q (via col ops on In) such that PAQ = [ Ir   0 ; 0   0 ].ρ(A) = r.

Solved Example 1.1: Rank by Row Echelon Form & Normal Form

Problem: Find the rank of the matrix A by reducing it to Row Echelon Form:

A = [  1   2   3   0 ]
    [  2   4   3   2 ]
    [  3   2   1   3 ]
    [  6   8   7   5 ]

Solution (Step-by-Step Row Reduction):

  1. Apply R2 → R2 − 2R1,  R3 → R3 − 3R1,  R4 → R4 − 6R1: 
    ~ [  1    2    3    0 ]
  [  0    0   -3    2 ]
  [  0   -4   -8    3 ]
  [  0   -4  -11    5 ]
  2. Interchange R2 ↔ R3 so the second row has a non-zero pivot in column 2: 
    ~ [  1    2    3    0 ]
  [  0   -4   -8    3 ]
  [  0    0   -3    2 ]
  [  0   -4  -11    5 ]
  3. Apply R4 → R4 − R2: 
    ~ [  1    2    3    0 ]
  [  0   -4   -8    3 ]
  [  0    0   -3    2 ]
  [  0    0   -3    2 ]
  4. Apply R4 → R4 − R3: 
    ~ [  1    2    3    0 ]
  [  0   -4   -8    3 ]
  [  0    0   -3    2 ]
  [  0    0    0    0 ]

This matrix is in Row Echelon Form with 3 non-zero rows. Hence, Rank ρ(A) = 3.

Linear Dependence and Independence of Vectors in Rn

Let X1, X2, …, Xk be k vectors in Rn, and consider the vector equation:

c1X1 + c2X2 + … + ckXk = 0

  • Linearly Independent (LI): If the only solution is the trivial solution c1 = c2 = … = ck = 0. Equivalently, if we form a matrix A with these k vectors as rows, then ρ(A) = k.
  • Linearly Dependent (LD): If there exist scalars ci (not all zero) satisfying the equation. Equivalently, ρ(A) < k (for k = n vectors in Rn, they are LD iff |A| = 0).

1.2 Consistency of System of Linear Equations (TSO 1b)

Consider a system of m linear equations in n unknowns written in matrix form as AX = B, where A is the m × n coefficient matrix and [A | B] is the m × (n + 1) augmented matrix.

Rouche's Theorem (Rank Test for Non-Homogeneous Systems AX = B)

Condition on RanksConsistencyNature of SolutionNumber of Free Variables
ρ(A) ≠ ρ([A | B]) (i.e. ρ(A) < ρ([A | B]))InconsistentNo Solution (Parallel / conflicting planes)None
ρ(A) = ρ([A | B]) = n (number of unknowns)ConsistentUnique Solution0
ρ(A) = ρ([A | B]) = r < nConsistentInfinitely Many Solutions(n − r) arbitrary parameters

Homogeneous System of Linear Equations (AX = 0)

Since ρ(A) = ρ([A | 0]) always holds, a homogeneous system AX = 0 is ALWAYS consistent:

  • Case 1: ρ(A) = n (or |A| ≠ 0 when m = n) ⇒ Only the Trivial Solution (X = 0) exists.
  • Case 2: ρ(A) = r < n (or |A| = 0 when m = n) ⇒ Infinitely many Non-Trivial Solutions exist with (n − r) linearly independent solutions (nullity of A).

Solved Example 1.2: Testing Consistency (Parameters λ and μ)

Problem: Investigate for what values of λ and μ the simultaneous equations x + y + z = 6, x + 2y + 3z = 10, x + 2y + λz = μ have: (i) no solution, (ii) a unique solution, (iii) an infinite number of solutions.

Solution: Write the augmented matrix [A | B] and apply R2 → R2 − R1, R3 → R3 − R1, followed by R3 → R3 − R2:

[A | B] = [ 1   1   1   |   6  ]      [ 1   1     1     |    6    ]
          [ 1   2   3   |  10  ]  ~   [ 0   1     2     |    4    ]
          [ 1   2   λ   |   μ  ]      [ 0   0   λ - 3   |  μ - 10 ]
  • (i) No Solution: Requires ρ(A) ≠ ρ([A | B]) ⇒ λ = 3 and μ ≠ 10 (gives ρ(A) = 2 ≠ ρ([A | B]) = 3).
  • (ii) Unique Solution: Requires ρ(A) = ρ([A | B]) = 3 ⇒ λ ≠ 3 and μ is any real number.
  • (iii) Infinite Solutions: Requires ρ(A) = ρ([A | B]) = 2 < 3 ⇒ λ = 3 and μ = 10.

1.3 Eigenvalues, Eigenvectors & Cayley-Hamilton Theorem (TSO 1c)

Let A be an n × n square matrix. A scalar λ is called an eigenvalue (characteristic root / latent root) and a non-zero column vector X ≠ 0 is called the corresponding eigenvector if:

AX = λX   ⟺   (A − λI)X = 0

For a non-trivial solution X ≠ 0, the characteristic determinant must vanish: |A − λI| = 0 (Characteristic Equation).

Shortcut for 3 × 3 Matrix: The characteristic polynomial of a 3 × 3 matrix A is:

λ3 − S1λ2 + S2λ − |A| = 0

where S1 = Trace(A) = a11 + a22 + a33,  S2 = Sum of minors of main diagonal elements, and |A| = Determinant of A.

Important Properties of Eigenvalues & Eigenvectors

  • Sum of Eigenvalues: λ1 + λ2 + … + λn = Trace(A) = Sum of main diagonal elements.
  • Product of Eigenvalues: λ1 · λ2 · … · λn = |A| (Determinant of A).
  • Powers & Inverse: If λ is an eigenvalue of A, then λk is an eigenvalue of Ak, and 1/λ is an eigenvalue of A−1 (with the same eigenvector X).
  • Triangular / Diagonal Matrix: The eigenvalues of an upper/lower triangular or diagonal matrix are simply its main diagonal entries.
  • Real Symmetric Matrix: All eigenvalues are purely real, and eigenvectors corresponding to distinct eigenvalues are mutually orthogonal (XiT Xj = 0).
  • Transpose: A and AT have the exact same characteristic equation and therefore the same eigenvalues.

Cayley-Hamilton Theorem (TSO 1c)

Statement: "Every square matrix satisfies its own characteristic equation."

If the characteristic equation of an n × n matrix A is |A − λI| = (−1)n [λn + c1λn−1 + c2λn−2 + … + cn] = 0, then replacing λ by the matrix A gives the matrix equation:

An + c1An−1 + c2An−2 + … + cnI = 0

  • To find A−1: Multiply the matrix equation by A−1 (valid when cn = (−1)n|A| ≠ 0):
    A−1 = −(1 / cn) [An−1 + c1An−2 + … + cn−1I].
  • To find higher integral powers (e.g., A4, A8): Express An = −c1An−1 − … − cnI and multiply successively by A, or divide the target polynomial f(λ) by the characteristic polynomial p(λ) so f(A) = r(A) where r(λ) is the remainder.

Solved Example 1.3: Cayley-Hamilton Theorem, A−1 and A4

Problem: Verify Cayley-Hamilton theorem for A = [ 2   −1   1 ; −1   2   −1 ; 1   −1   2 ] and hence find A−1 and A4.

Solution:

  1. Characteristic Equation:
    • S1 = Trace(A) = 2 + 2 + 2 = 6
    • S2 = (4 − 1) + (4 − 1) + (4 − 1) = 3 + 3 + 3 = 9
    • |A| = 2(3) − (−1)(−1) + 1(−1) = 6 − 1 − 1 = 4
    Hence the characteristic equation is λ3 − 6λ2 + 9λ − 4 = 0 (whose roots are λ = 1, 1, 4).
  2. Cayley-Hamilton Verification: By Cayley-Hamilton theorem, A3 − 6A2 + 9A − 4I = 0.
    Computing A2 = [ 6   −5   5 ; −5   6   −5 ; 5   −5   6 ] and A3 = [ 22   −21   21 ; −21   22   −21 ; 21   −21   22 ]:
    A3 − 6A2 + 9A − 4I = [ 22 − 36 + 18 − 4, … ] = 03×3 (Verified!).
  3. Finding A−1: Multiply by A−1:
    4A−1 = A2 − 6A + 9I
    A−1 = (1/4) ( [ 6   −5   5 ; −5   6   −5 ; 5   −5   6 ] − [ 12   −6   6 ; −6   12   −6 ; 6   −6   12 ] + [ 9   0   0 ; 0   9   0 ; 0   0   9 ] )
    A−1 = (1/4) [ 3   1   −1 ; 1   3   1 ; −1   1   3 ].
  4. Finding A4: Since A3 = 6A2 − 9A + 4I, multiply by A:
    A4 = 6A3 − 9A2 + 4A = 6(6A2 − 9A + 4I) − 9A2 + 4A = 27A2 − 50A + 24I.
    Substituting A2, A, I gives A4 = [ 86   −85   85 ; −85   86   −85 ; 85   −85   86 ].

1.4 Similarity of Matrices, Diagonalization, Quadratic & Canonical Forms (TSO 1d)

Similarity of Matrices

Two n × n matrices A and B are said to be similar if there exists an invertible (non-singular) matrix P such that:

B = P−1 A P

  • Similar matrices have the same characteristic polynomial, eigenvalues, determinant, trace, and rank.

Diagonalization of a Square Matrix

An n × n matrix A is diagonalizable if it has n linearly independent eigenvectors X1, …, Xn. Let P = [X1   X2   …   Xn] be the modal matrix. Then:

P−1 A P = D = diag(λ1, λ2, …, λn)

  • Allows fast matrix powers: Ak = P Dk P−1.
  • If A is real symmetric, it can be orthogonally diagonalized: NT A N = D, where N has orthonormalized eigenvectors (N−1 = NT).

Quadratic Forms and Canonical (Sum of Squares) Form (TSO 1d)

A homogeneous polynomial of second degree in n variables X = [x1, x2, …, xn]T is called a Quadratic Form:

Q = XT A X = ∑i=1n ∑j=1n aij xi xj

For 3 variables (x, y, z): Q = ax2 + by2 + cz2 + 2f yz + 2g zx + 2h xy, where the symmetric matrix A is written with diagonal elements (a, b, c) and off-diagonal elements a12 = a21 = h (half of the coefficient of xy), a13 = a31 = g (half of xz), and a23 = a32 = f (half of yz).

Canonical Form (Sum of Squares Form): By an orthogonal transformation X = NY (where N is the normalized modal matrix of A), the quadratic form reduces to:

Q = YT (NT A N) Y = λ1 y12 + λ2 y22 + … + λn yn2

  • Rank of Q (r): Total number of non-zero eigenvalues (non-zero squared terms in canonical form).
  • Index of Q (p): Number of positive eigenvalues (positive terms in canonical form).
  • Signature of Q (s): Difference between positive and negative terms: s = p − (r − p) = 2p − r.

Nature of a Quadratic Form (Eigenvalue & Sylvester's Principal Minor Criteria)

Nature of Quadratic Form QEigenvalue Condition (λ1, …, λn)Principal Minor Condition (Δ1, Δ2, Δ3)
1. Positive Definite (Q > 0 for all X ≠ 0)All eigenvalues are strictly positive (λi > 0 for all i)All leading principal minors are positive: Δ1 > 0, Δ2 > 0, Δ3 > 0
2. Negative Definite (Q < 0 for all X ≠ 0)All eigenvalues are strictly negative (λi < 0 for all i)Leading principal minors alternate in sign: Δ1 < 0, Δ2 > 0, Δ3 < 0
3. Positive Semidefinite (Q ≥ 0)All λi ≥ 0 and at least one λi = 0All principal minors ≥ 0 and |A| = 0
4. Negative Semidefinite (Q ≤ 0)All λi ≤ 0 and at least one λi = 0|A| = 0 and odd/even principal minors ≤ 0 / ≥ 0
5. Indefinite (Q takes both + and − signs)Some eigenvalues are positive (λi > 0) and some are negative (λj < 0)Fails the definite / semidefinite conditions above

Solved Example 1.4: Canonical Form, Rank, Index, Signature & Nature of Quadratic Form

Problem: Reduce the quadratic form Q = 3x2 + 5y2 + 3z2 − 2yz + 2zx − 2xy to canonical form by orthogonal transformation and find its rank, index, signature, and nature.

Solution:

  1. Symmetric Matrix A of Q: Half the coefficients of xy, yz, zx give a12 = −1, a23 = −1, a13 = 1: 
    A = [  3  -1   1 ]
    [ -1   5  -1 ]
    [  1  -1   3 ]
  2. Eigenvalues of A:
    • S1 = 3 + 5 + 3 = 11
    • S2 = (15 − 1) + (9 − 1) + (15 − 1) = 14 + 8 + 14 = 36
    • |A| = 3(14) − (−1)(−2) + 1(−4) = 42 − 2 − 4 = 36
    Characteristic equation: λ3 − 11λ2 + 36λ − 36 = 0 ⇒ (λ − 2)(λ − 3)(λ − 6) = 0.
    Thus the eigenvalues are λ1 = 2,  λ2 = 3,  λ3 = 6.
  3. Canonical Form: Under orthogonal transformation X = NY, the canonical form is:
    Q = 2y12 + 3y22 + 6y32
  4. Parameters & Nature:
    • Rank (r) = 3 (all 3 eigenvalues are non-zero)
    • Index (p) = 3 (all 3 eigenvalues are positive)
    • Signature (s) = 2p − r = 2(3) − 3 = 3
    • Nature: Since all eigenvalues (2, 3, 6) > 0, the quadratic form is Positive Definite.
