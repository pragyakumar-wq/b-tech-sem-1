4.1 Differentiation Under the Integral Sign — Leibnitz's Rule (TSO 4a)

1. Constant Limits of Integration [a, b]: Let I(α) = ∫ab f(x, α) dx, where f(x, α) and ∂f/∂α are continuous on [a, b] × [α1, α2]. Then:

dI / dα = d/dα [ ∫ab f(x, α) dx ] = ∫ab [ ∂f(x, α) / ∂α ] dx

2. General Leibnitz's Rule (Variable Limits u(α) and v(α)): If I(α) = ∫u(α)v(α) f(x, α) dx, then:

dI / dα = ∫u(α)v(α) [ ∂f(x, α) / ∂α ] dx + f(v(α), α) · (dv / dα) − f(u(α), α) · (du / dα)

Solved Example 4.1: Evaluating a Definite Integral Using Leibnitz's Rule

Problem: Using differentiation under the integral sign (Leibnitz's Rule), evaluate I(α) = ∫0π log(1 + α cos x) dx for |α| < 1.

Solution:

  1. Differentiate I(α) with respect to the parameter α under the integral sign (since limits 0 and π are constants):
    dI / dα = ∫0π (∂/∂α) [ log(1 + α cos x) ] dx = ∫0π [ cos x / (1 + α cos x) ] dx.
  2. Rewrite the numerator as (1/α)[ (1 + α cos x) − 1 ]:
    dI / dα = (1/α) ∫0π [ 1 − 1 / (1 + α cos x) ] dx = (1/α) [ π − π / √(1 − α2) ]
    (using the standard integral ∫0π dx / (1 + α cos x) = π / √(1 − α2) for |α| < 1).
  3. Integrate with respect to α:
    I(α) = π ∫ [ 1/α − 1 / (α √(1 − α2)) ] dα = π log [ (1 + √(1 − α2)) / 2 ] + C.
  4. Find constant C using α = 0: I(0) = ∫0π log(1) dx = 0 ⇒ π log(1) + C = 0 ⇒ C = 0.
    Hence, ∫0π log(1 + α cos x) dx = π log [ (1 + √(1 − α2)) / 2 ].

Solved Example 4.2: Change of Order of Integration

Problem: Evaluate by changing the order of integration: I = ∫01 ∫x1 [ x / (x2 + y2) ] dy dx (or I = ∫0∞ ∫x∞ (e−y / y) dy dx).

Solution (for I = ∫0∞ ∫x∞ (e−y / y) dy dx):

  1. Identify the Region of Integration R:
    The given limits are y = x to y = ∞ (vertical strip) and x = 0 to x = ∞. This is the infinite wedge above the line y = x in the first quadrant.
  2. Switch to a Horizontal Strip (dx dy):
    For a fixed y ∈ [0, ∞), x varies from the y-axis (x = 0) to the line (x = y), and then y varies from 0 to ∞.
  3. Evaluate the New Integral:
    I = ∫y=0∞ [ ∫x=0y (e−y / y) dx ] dy = ∫0∞ (e−y / y) [ x ]0y dy = ∫0∞ (e−y / y) · y dy = ∫0∞ e−y dy = [ −e−y ]0∞ = 1.

4.3 Triple Integrals & Cylindrical / Spherical Polar Coordinates (TSO 4c)

For a 3D solid region V, the triple integral of f(x, y, z) is ∭V f(x, y, z) dV. When f(x, y, z) = 1, the triple integral gives the Volume of the 3-D solid: V = ∭V dx dy dz.

Solved Example 4.3: Triple Integral in Spherical Polar Coordinates

Problem: Evaluate ∭V (x2 + y2 + z2) dx dy dz over the sphere x2 + y2 + z2 ≤ a2.

Solution: Convert to Spherical Polar Coordinates: x2 + y2 + z2 = r2 and dx dy dz = r2 sin θ dr dθ dφ.
For the full sphere of radius a, the limits are: 0 ≤ r ≤ a,  0 ≤ θ ≤ π,  0 ≤ φ ≤ 2π:

I = ∫φ=02π dφ · ∫θ=0π sin θ dθ · ∫r=0a r2 · r2 dr = [ 2π ] · [ −cos θ ]0π · [ r5 / 5 ]0a = 2π · 2 · (a5 / 5) = 4π a5 / 5.

4.4 Beta, Gamma & Elliptic Integrals (TSO 4d)

1. Gamma Function — Γ(n)

For n > 0, Euler's Gamma function is defined by the improper integral:

Γ(n) = ∫0∞ e−x xn−1 dx

  • Recurrence Relation: Γ(n + 1) = n Γ(n)
  • Positive Integer n: Γ(n + 1) = n!  (and Γ(1) = 1)
  • Half-Integer Value: Γ(1/2) = √π,  Γ(3/2) = (1/2)√π
  • Substitution Form: ∫0∞ e−kx xn−1 dx = Γ(n) / kn (k > 0)

2. Beta Function — β(m, n)

For m > 0, n > 0, the Beta function is defined by:

β(m, n) = ∫01 xm−1 (1 − x)n−1 dx

  • Symmetry: β(m, n) = β(n, m)
  • Infinite Limit Form: β(m, n) = ∫0∞ [ xm−1 / (1 + x)m+n ] dx
  • Trigonometric Form:
    ∫0π/2 sinp θ cosq θ dθ = (1/2) β( (p+1)/2 , (q+1)/2 )

Key Relations Between Beta and Gamma Functions

  • Fundamental Beta-Gamma Relation: β(m, n) = [ Γ(m) Γ(n) ] / Γ(m + n)
  • Wallis / Sine-Cosine Formula: ∫0π/2 sinp θ cosq θ dθ = [ Γ((p+1)/2) Γ((q+1)/2) ] / [ 2 Γ((p+q+2)/2) ]
  • Euler's Reflection Formula: Γ(n) Γ(1 − n) = π / sin(nπ)  (for 0 < n < 1)
  • Legendre's Duplication Formula: Γ(m) Γ(m + 1/2) = [ √π / 22m−1 ] Γ(2m)
  • Elliptic Integrals (Overview): For modulus 0 < k < 1:
    • Complete Elliptic Integral of the First Kind: K(k) = ∫0π/2 dθ / √(1 − k2 sin2 θ) (used for exact time period of a simple pendulum at large amplitudes).
    • Complete Elliptic Integral of the Second Kind: E(k) = ∫0π/2 √(1 − k2 sin2 θ) dθ (used to find the arc length of an ellipse).

Solved Example 4.4: Evaluating Improper Integrals Using Beta & Gamma Functions

Problem: Evaluate (i) ∫0∞ √x e−x3 dx and (ii) ∫0π/2 √(tan θ) dθ.

Solution:

  1. Part (i): Put x3 = t ⇒ x = t1/3 ⇒ dx = (1/3) t−2/3 dt.
    Then ∫0∞ x1/2 e−x3 dx = (1/3) ∫0∞ t1/6 e−t t−2/3 dt = (1/3) ∫0∞ e−t t−1/2 dt = (1/3) ∫0∞ e−t t(1/2)−1 dt = (1/3) Γ(1/2) = √π / 3.
  2. Part (ii): Rewrite √(tan θ) = sin1/2 θ cos−1/2 θ (so p = 1/2, q = −1/2):
    ∫0π/2 sin1/2 θ cos−1/2 θ dθ = [ Γ(3/4) Γ(1/4) ] / [ 2 Γ(1) ] = (1/2) · [ π / sin(π/4) ] = (1/2) · (π / (1/√2)) = π / √2.
