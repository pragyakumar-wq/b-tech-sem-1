Question 4 · Unit 4 (CO4)

Evaluate ∫01 ∫x22−x xy dy dx by changing the order of integration. Also prove the Beta-Gamma relation β(m, n) = Γ(m)Γ(n) / Γ(m + n) and evaluate ∫0π/2 √(sin θ) dθ × ∫0π/2 dθ / √(sin θ).

Part A: Evaluation by Changing the Order of Integration

Given Integral: I = ∫x=01 ∫y=x22−x x y dy dx

  1. Boundary Curves & Region R:
    The lower curve is the parabola y = x2 and the upper curve is the line y = 2 − x. They intersect in the first quadrant at x2 = 2 − x ⇒ (x + 2)(x − 1) = 0 ⇒ (1, 1).
    The y-coordinate runs from y = 0 (at origin) to y = 1 (at intersection) and up to y = 2 (where y = 2 − x meets the y-axis at (0, 2)).
  2. Horizontal Strip Split at y = 1:
    When switching to horizontal strips (dx dy), the right boundary changes at y = 1:
    • Region R1 (0 ≤ y ≤ 1): x goes from x = 0 to the parabola x = √y.
    • Region R2 (1 ≤ y ≤ 2): x goes from x = 0 to the line x = 2 − y.
  3. Evaluate I = I1 + I2:
    I = ∫y=01 ∫x=0√y x y dx dy + ∫y=12 ∫x=02−y x y dx dy
    • I1 = ∫01 y [ x2/2 ]0√y dy = (1/2) ∫01 y2 dy = (1/2)(1/3) = 1 / 6.
    • I2 = ∫12 y [ x2/2 ]02−y dy = (1/2) ∫12 (4y − 4y2 + y3) dy = (1/2) [ 2y2 − (4/3)y3 + y4/4 ]12 = (1/2)(5/12) = 5 / 24.
    • Total: I = 1/6 + 5/24 = 9 / 24 = 3 / 8.

Part B: Beta-Gamma Relation & Product of Trigonometric Integrals

1. Outline of Proof of β(m, n) = Γ(m)Γ(n) / Γ(m + n):

  • Start from Γ(m) = 2 ∫0∞ e−x2 x2m−1 dx and Γ(n) = 2 ∫0∞ e−y2 y2n−1 dy.
  • Multiply: Γ(m)Γ(n) = 4 ∫0∞ ∫0∞ e−(x2+y2) x2m−1 y2n−1 dx dy.
  • Transform to polar coordinates x = r cos θ, y = r sin θ, dx dy = r dr dθ over the first quadrant (0 ≤ r < ∞, 0 ≤ θ ≤ π/2):
    Γ(m)Γ(n) = [ 2 ∫0∞ e−r2 r2(m+n)−1 dr ] · [ 2 ∫0π/2 cos2m−1 θ sin2n−1 θ dθ ] = Γ(m + n) · β(m, n).

2. Evaluation of P = [ ∫0π/2 sin1/2 θ dθ ] × [ ∫0π/2 sin−1/2 θ dθ ]:
Using ∫0π/2 sinp θ cos0 θ dθ = [ Γ((p+1)/2) Γ(1/2) ] / [ 2 Γ((p+3)/2) ]:

  • For the first integral (p = 1/2, q = 0): I1 = [ Γ(3/4) Γ(1/2) ] / [ 2 Γ(5/4) ].
  • For the second integral (p = −1/2, q = 0): I2 = [ Γ(1/4) Γ(1/2) ] / [ 2 Γ(3/4) ].
  • Multiply I1 × I2 (noting Γ(5/4) = (1/4)Γ(1/4) and [Γ(1/2)]2 = π):
    P = I1 · I2 = [ Γ(3/4) Γ(1/4) · π ] / [ 4 · (1/4) Γ(1/4) Γ(3/4) ] = π.
