5.1 Gradient, Divergence, Curl, Directional Derivative & Tangent Plane (TSO 5a)

Vector Differential Operator Del (∇): In 3D Cartesian coordinates with unit vectors i, j, k:

∇ = i (∂/∂x) + j (∂/∂y) + k (∂/∂z)

Let φ(x, y, z) be a differentiable scalar point function (e.g., temperature, electrostatic potential) and F(x, y, z) = F1 i + F2 j + F3 k be a differentiable vector point function (e.g., velocity field, force field, electric/magnetic field).

Differential OperationMathematical FormulaOutput TypeGeometrical & Physical Significance
1. Gradient of Scalar Field
grad φ = ∇φ		∇φ = (∂φ/∂x)i + (∂φ/∂y)j + (∂φ/∂z)kVector Field• Points in the direction of maximum rate of increase of φ.
• Magnitude |∇φ| is the maximum rate of change.
• Always perpendicular (normal) to the level surface φ(x, y, z) = c.
2. Directional Derivative (D.D.)
along vector a		D.D. = ∇φ · â = ∇φ · (a / |a|)ScalarComponent of ∇φ in the direction of unit vector â = a / |a|; measures rate of change of φ along a.
3. Divergence of Vector Field
div F = ∇ · F		∇ · F = ∂F1/∂x + ∂F2/∂y + ∂F3/∂zScalar Field• Measures the net outward flux per unit volume from an infinitesimal point (source if ∇·F > 0, sink if ∇·F < 0).
• If ∇ · F = 0 everywhere, F is called Solenoidal (incompressible fluid / magnetic field ∇·B = 0).
4. Curl of Vector Field
curl F = ∇ × F		∇ × F = | i   j   k ; ∂/∂x   ∂/∂y   ∂/∂z ; F1   F2   F3 |Vector Field• Measures local circulation / rotation (vorticity) per unit area; for a rigid body rotating with angular velocity ω, v = ω × r ⇒ ∇ × v = 2ω.
• If ∇ × F = 0 everywhere, F is called Irrotational (Conservative) and F = ∇φ for a scalar potential φ.
5. Laplacian Operator
∇2φ = div(grad φ)		∇2φ = ∂2φ/∂x2 + ∂2φ/∂y2 + ∂2φ/∂z2Scalar FieldIf ∇2φ = 0, φ satisfies Laplace's Equation and is called a Harmonic Function.

Tangent Plane, Normal Line & Angle Between Two Surfaces

  • Unit Normal Vector (n̂) to Surface φ(x, y, z) = c at P(x0, y0, z0): n̂ = ± ∇φ / |∇φ|.
  • Equation of Tangent Plane at P(x0, y0, z0): (x − x0)(∂φ/∂x)P + (y − y0)(∂φ/∂y)P + (z − z0)(∂φ/∂z)P = 0.
  • Equation of Normal Line at P(x0, y0, z0): (x − x0) / (∂φ/∂x)P = (y − y0) / (∂φ/∂y)P = (z − z0) / (∂φ/∂z)P.
  • Angle θ between Two Surfaces φ1 = c1 and φ2 = c2 at intersection point P:
    cos θ = (∇φ1 · ∇φ2) / ( |∇φ1| |∇φ2| ). (Orthogonal surfaces if ∇φ1 · ∇φ2 = 0).
  • Fundamental Vector Identities: For any scalar field φ and vector field F:
    1. curl(grad φ) = ∇ × (∇φ) = 0 (Every gradient field is irrotational).
    2. div(curl F) = ∇ · (∇ × F) = 0 (Every curl field is solenoidal).
    3. For position vector r = xi + yj + zk (r = |r|): ∇ · r = 3,  ∇ × r = 0,  ∇(rn) = n rn−2 r,  ∇ · (rn r) = (n + 3)rn (so rnr is solenoidal when n = −3).

Solved Example 5.1: Directional Derivative, Solenoidal & Irrotational Vectors

Problem: (a) Find the directional derivative of φ = x2yz + 4xz2 at (1, −2, −1) in the direction of 2i − j − 2k.
(b) Find constants a, b, c so that F = (x + 2y + az)i + (bx − 3y − z)j + (4x + cy + 2z)k is irrotational, and find its scalar potential φ.

Solution:

  1. Part (a): ∇φ = (2xyz + 4z2)i + (x2z)j + (x2y + 8xz)k.
    At (1, −2, −1): ∇φ = (4 + 4)i + (−1)j + (−2 − 8)k = 8i − j − 10k.
    Unit vector â = (2i − j − 2k) / √(4 + 1 + 4) = (2i − j − 2k) / 3.
    D.D. = ∇φ · â = [ 8(2) + (−1)(−1) + (−10)(−2) ] / 3 = (16 + 1 + 20) / 3 = 37 / 3.
  2. Part (b): For F to be irrotational, ∇ × F = 0:
    ∇ × F = i(c − (−1)) − j(4 − a) + k(b − 2) = (c + 1)i − (4 − a)j + (b − 2)k = 0.
    Equating components to zero gives: a = 4,  b = 2,  c = −1.
    Then F = (x + 2y + 4z)i + (2x − 3y − z)j + (4x − y + 2z)k = ∇φ.
    Integrating partially and combining non-duplicate terms gives the scalar potential:
    φ(x, y, z) = x2/2 − 3y2/2 + z2 + 2xy + 4xz − yz + C.

5.2 Line, Surface & Volume Integrals — Green's, Stokes' & Gauss' Theorems (TSO 5b, 5c)

  • Line Integral (Work Done / Circulation): Along a curve C with dr = dx i + dy j + dz k:
    W = ∫C F · dr = ∫C (F1 dx + F2 dy + F3 dz).
    If F = ∇φ is conservative (irrotational), the line integral is independent of path: ∫AB F · dr = φ(B) − φ(A), and around any closed loop ∮C F · dr = 0.
  • Surface Integral (Flux Across Surface S): If n̂ is the unit outward normal to surface S (and projection on xy-plane has dS = dx dy / |n̂ · k|):
    Flux = ∬S F · n̂ dS = ∬S F · dS.
  • Volume Integral: Over a 3D region V: ∭V (∇ · F) dV = ∭V (∂F1/∂x + ∂F2/∂y + ∂F3/∂z) dx dy dz.

Master Comparison of Green's, Stokes', and Gauss' Divergence Theorems

TheoremMathematical StatementIntegral ConversionConditions & Key Applications
1. Green's Theorem in the Plane∮C (M dx + N dy) = ∬R ( ∂N/∂x − ∂M/∂y ) dx dyClosed Line Integral (1D) ⟷ Double Integral over Plane Region R (2D)C is a simple closed curve bounding plane region R traversed counter-clockwise.
• Area of plane region: Area = (1/2) ∮C (x dy − y dx).
2. Stokes' Theorem (TSO 5b)∮C F · dr = ∬S (∇ × F) · n̂ dSClosed Line Integral in 3D (1D) ⟷ Surface Integral of Curl (2D)S is an open, two-sided surface in 3D space bounded by closed curve C; orientation follows the right-hand rule.
• Reduces to Green's theorem when S lies in the xy-plane.
3. Gauss' Divergence Theorem (TSO 5c)∬S F · n̂ dS = ∭V (∇ · F) dVClosed Surface Flux Integral (2D) ⟷ Volume Integral of Divergence (3D)S is a closed surface enclosing 3D volume V, and n̂ is the outward-pointing unit normal.
• Since ∇ · r = 3, ∬S r · n̂ dS = 3V.

Solved Example 5.2: Evaluation Using Gauss' Divergence Theorem (TSO 5c)

Problem: Apply Gauss' Divergence Theorem to evaluate the surface integral ∬S F · n̂ dS, where F = 4xz i − y2 j + yz k and S is the surface of the cube bounded by x = 0, x = 1, y = 0, y = 1, z = 0, z = 1.

Solution:

  1. Compute the divergence of F = 4xz i − y2 j + yz k:
    ∇ · F = ∂(4xz)/∂x + ∂(−y2)/∂y + ∂(yz)/∂z = 4z − 2y + y = 4z − y.
  2. By Gauss' Divergence Theorem, convert the closed surface integral over the 6 faces of the cube into a single volume integral over 0 ≤ x ≤ 1, 0 ≤ y ≤ 1, 0 ≤ z ≤ 1:
    ∬S F · n̂ dS = ∭V (∇ · F) dV = ∫x=01 ∫y=01 ∫z=01 (4z − y) dz dy dx.
  3. Evaluate the inner integrals:
    • ∫z=01 (4z − y) dz = [ 2z2 − yz ]01 = 2 − y.
    • ∫y=01 (2 − y) dy = [ 2y − y2/2 ]01 = 2 − 1/2 = 3/2.
    • ∫x=01 (3/2) dx = 3 / 2.
