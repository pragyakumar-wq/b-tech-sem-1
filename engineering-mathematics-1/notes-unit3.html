3.1 Partial Differentiation & Euler's Theorem on Homogeneous Functions (TSO 3a)

Partial Derivatives & Standard Monge's Notation: For a function of two independent variables z = f(x, y), partial derivatives are obtained by differentiating with respect to one variable while treating the other variable as a constant:

  • First-Order Partial Derivatives: p = ∂z/∂x = fx ,   q = ∂z/∂y = fy
  • Second-Order Partial Derivatives: r = ∂2z/∂x2 = fxx ,   s = ∂2z/∂x∂y = fxy ,   t = ∂2z/∂y2 = fyy
  • Schwarz's / Clairaut's Theorem: If fxy and fyx are continuous in a region, then the mixed partial derivatives are equal: ∂2z / ∂x∂y = ∂2z / ∂y∂x.

Homogeneous Functions & Euler's Theorems (TSO 3a)

Homogeneous Function of Degree n: A function f(x, y) is said to be homogeneous of degree n if for any scale factor t > 0:

f(tx, ty) = tn f(x, y)    ⟺    f(x, y) = xn φ(y/x) = yn ψ(x/y)

1. Euler's First-Order Theorem: If u = f(x, y) is a homogeneous function of degree n with continuous first-order partial derivatives, then:

x (∂u / ∂x) + y (∂u / ∂y) = n u

(For m variables x1, x2, …, xm:  ∑i=1m xi (∂u / ∂xi) = n u).

2. Euler's Second-Order Deduction: If u = f(x, y) is homogeneous of degree n with continuous second-order partial derivatives, then:

x2 (∂2u / ∂x2) + 2xy (∂2u / ∂x∂y) + y2 (∂2u / ∂y2) = n(n − 1) u

3. Deduction for Composite Homogeneous Functions u = F(v) where v = φ(u) is Homogeneous of Degree n:

  • x (∂u / ∂x) + y (∂u / ∂y) = n · [ φ(u) / φ'(u) ] = g(u)
  • x2 uxx + 2xy uxy + y2 uyy = g(u) [ g'(u) − 1 ]

Solved Example 3.1: Euler's Theorem on Composite Homogeneous Functions

Problem: If u = sin−1[ (x2 + y2) / (x + y) ], prove that x (∂u/∂x) + y (∂u/∂y) = tan u and x2 uxx + 2xy uxy + y2 uyy = tan u (sec2 u − 1) = tan3 u.

Solution:

  1. Rewrite the relation as: v = sin u = (x2 + y2) / (x + y).
  2. Check homogeneity of v(x, y): v(tx, ty) = t2(x2 + y2) / [t(x + y)] = t1 v(x, y).
    Thus v = sin u is a homogeneous function of degree n = 1.
  3. By Euler's Theorem on v = φ(u) = sin u:
    x (∂u/∂x) + y (∂u/∂y) = n · [ φ(u) / φ'(u) ] = 1 · (sin u / cos u) = tan u = g(u).
  4. By the second-order deduction with g(u) = tan u and g'(u) = sec2 u:
    x2 uxx + 2xy uxy + y2 uyy = g(u) [g'(u) − 1] = tan u (sec2 u − 1) = tan3 u. (Hence Proved!)

3.3 Taylor's & Maclaurin's Theorem for Two Variables (TSO 3c)

Taylor's Theorem in the Neighborhood of (a, b): If f(x, y) and its partial derivatives up to order n are continuous in a neighborhood of (a, b), then setting h = x − a and k = y − b:

f(x, y) = f(a, b) + [ (x − a)fx(a,b) + (y − b)fy(a,b) ] + (1/2!) [ (x − a)2fxx(a,b) + 2(x − a)(y − b)fxy(a,b) + (y − b)2fyy(a,b) ] + (1/3!) [ (x − a)(∂/∂x) + (y − b)(∂/∂y) ]3 f(a, b) + … + Rn

where Lagrange's Form of Remainder after n terms is:

Rn = (1 / n!) [ (x − a)(∂/∂x) + (y − b)(∂/∂y) ]n f(a + θh, b + θk) ,    0 < θ < 1.

Maclaurin's Series (Special Case at Origin a = 0, b = 0):

f(x, y) = f(0,0) + [ x fx(0,0) + y fy(0,0) ] + (1/2!) [ x2 fxx(0,0) + 2xy fxy(0,0) + y2 fyy(0,0) ] + …

Solved Example 3.2: Taylor's Series Expansion About (1, 1)

Problem: Expand f(x, y) = x2y + 3y − 2 in powers of (x − 1) and (y − 1) using Taylor's theorem.

Solution: Evaluate f and all its partial derivatives at (a, b) = (1, 1):

  • f(x, y) = x2y + 3y − 2   ⇒   f(1, 1) = 1 + 3 − 2 = 2
  • fx = 2xy ⇒ fx(1,1) = 2 ;    fy = x2 + 3 ⇒ fy(1,1) = 4
  • fxx = 2y ⇒ fxx(1,1) = 2 ;    fxy = 2x ⇒ fxy(1,1) = 2 ;    fyy = 0 ⇒ fyy(1,1) = 0
  • fxxx = 0,   fxxy = 2 ⇒ fxxy(1,1) = 2,   fxyy = 0,   fyyy = 0 (all higher derivatives are 0).

Substituting into Taylor's formula:
f(x, y) = 2 + [ 2(x − 1) + 4(y − 1) ] + (1/2!)[ 2(x − 1)2 + 4(x − 1)(y − 1) ] + (1/3!)[ 3 · 2(x − 1)2(y − 1) ]
f(x, y) = 2 + 2(x − 1) + 4(y − 1) + (x − 1)2 + 2(x − 1)(y − 1) + (x − 1)2(y − 1).

3.4 Maxima & Minima of Functions of Several Variables & Lagrange's Multipliers (TSO 3d)

1. Unconstrained Extrema of f(x, y) — The (rt − s2) Second Derivative Test

Step 1 (Stationary / Critical Points): Solve simultaneous equations p = ∂f/∂x = 0 and q = ∂f/∂y = 0 to find stationary points (a, b).

Step 2 (Hessian Discriminant): At each stationary point (a, b), compute r = fxx(a,b), s = fxy(a,b), t = fyy(a,b), and Δ = rt − s2:

  • If rt − s2 > 0 and r < 0: f(x, y) has a Local Maximum at (a, b).
  • If rt − s2 > 0 and r > 0: f(x, y) has a Local Minimum at (a, b).
  • If rt − s2 < 0: (a, b) is a Saddle Point (neither maximum nor minimum).
  • If rt − s2 = 0: Test is inconclusive (further investigation of increment Δf required).

2. Constrained Optimization: Lagrange's Method of Undetermined Multipliers (TSO 3d)

To find the stationary (extreme) values of an objective function u = f(x, y, z) subject to the constraint equation φ(x, y, z) = 0:

  1. Construct the Lagrangian Auxiliary Function using an undetermined multiplier λ:
    F(x, y, z, λ) = f(x, y, z) + λ φ(x, y, z)
  2. Set the partial derivatives with respect to x, y, z to zero:
    ∂F/∂x = ∂f/∂x + λ(∂φ/∂x) = 0 ,    ∂F/∂y = ∂f/∂y + λ(∂φ/∂y) = 0 ,    ∂F/∂z = ∂f/∂z + λ(∂φ/∂z) = 0
  3. Solve these three equations together with the constraint φ(x, y, z) = 0 to determine λ and the optimal point (x, y, z).

Solved Example 3.3: Engineering Design Optimization Using Lagrange's Multipliers

Problem: A rectangular box, open at the top, is to have a given capacity (volume) of V = 32 cubic meters. Find the dimensions of the box requiring the least material (minimum surface area) for its construction.

Solution:

  1. Objective & Constraint: Let x, y, z be the length, breadth, and height of the open-top box.
    • Surface area to minimize: S = xy + 2yz + 2zx
    • Volume constraint: φ(x, y, z) = xyz − 32 = 0.
  2. Lagrangian Function: F(x, y, z, λ) = (xy + 2yz + 2zx) + λ(xyz − 32).
  3. First-Order Conditions:
    • ∂F/∂x = y + 2z + λ yz = 0   ⇒   λ = −(1/z + 2/y)
    • ∂F/∂y = x + 2z + λ xz = 0   ⇒   λ = −(1/z + 2/x)
    • ∂F/∂z = 2y + 2x + λ xy = 0   ⇒   λ = −(2/x + 2/y)
  4. Solve for x, y, z:
    Equating the first two expressions for λ gives x = y.
    Equating the second and third gives 1/z = 2/y ⇒ y = 2z.
    Hence x = y = 2z. Substitute into the constraint xyz = 32:
    (2z)(2z)(z) = 32 ⇒ 4z3 = 32 ⇒ z3 = 8 ⇒ z = 2 m.
    Therefore, x = 4 m,  y = 4 m,  z = 2 m, and minimum surface area Smin = 16 + 16 + 16 = 48 m2.
